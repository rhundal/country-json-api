🗺️ Project Overview

• Purpose: This repository hosts a static JSON dataset representing global country profiles to simulate a remote REST API.
• Use Case: Built to practice front-end asynchronous operations, data fetching, and handling cross-origin network requests on my one of my projects.

🌐 Endpoint Information

• Base Endpoint: List your live GitHub Pages URL (e.g., https://rhundal.github.io/country-json-api/data.json).
• HTTP Method: Supports GET requests only.
• Content-Type: Serves data as standard application/json.
